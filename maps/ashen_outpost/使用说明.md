# 灰烬前哨 ASHEN-43

Minecraft Java 1.20.1 炮台视频录制地图。以《绝地潜兵》风格的荒漠工业前哨为主题，手工设计区域 768 × 768 格；地图建筑只使用原版方块。录制本项目炮台时，使用你现有的 SBW Helldivers 和卓越前线环境即可。

## 安装

1. 解压 `灰烬前哨_炮台录制地图_1.20.1.zip`。
2. 将其中 **HD2_Ashen_Outpost** 文件夹复制到你实际启动的 Minecraft 实例的 `saves` 文件夹。这个文件夹内应直接看到 `level.dat`、`region` 和 `datapacks`。
3. 在单人游戏中打开“灰烬前哨 ASHEN-43 · 炮台摄影场”。默认创造模式、允许命令、固定晴天。
4. 出生点附近的控制台有近距靶群、远距靶群、清除靶群和日间按钮。快捷栏第一格及控制台右侧木桶中都有拍摄手册，打开后可以点击文字切换机位和时间。

地图没有预置炮台，也不会自动生成怪物。存档自带控制数据包，请保留 `datapacks/ashen_outpost`。

## 场景与用途

| 区域 | 位置约值 | 用途 |
| --- | --- | --- |
| 主展示平台 | 0, 70, -25 | 空投、展开、供弹和炮台特写；前方为 +Z |
| 左右副平台 | ±40, 68, -20 | 侧面镜头、两种炮台对比 |
| 飞鹰停机坪 | 0, 68, -108 | 飞鹰模型展示、片头与远景 |
| 机库维修区 | -79, 67, -70 | 工具架、炉组、维修台、吊灯、格栅和通风设备 |
| 指挥室 | 80, 68, -73 | 控制台、地图桌、设备柜和感应铁门 |
| 雷达站 | 119, 79, 61 | 工业背景、侧面构图 |
| 双塔靶场 | 约 0, 64, 150 | 中远距射击、飞鹰通场与爆炸背景 |

测距标线按主平台中心 Z=-25 计算，标注为水平距离。固定靶群为 30 米与 100 米，每组 5 只不移动的尸壳，各 100 生命值。重复生成会先清除旧组；“清除靶群”只作用于本地图专用标签的靶怪，不会删除你摆放的炮台或其他生物。

## 拍摄快捷命令

也可直接在聊天栏执行：

```mcfunction
/function outpost:camera/main
/function outpost:camera/side
/function outpost:camera/wide
/function outpost:camera/eagle
/function outpost:camera/spawn
/function outpost:light/day
/function outpost:light/sunset
/function outpost:light/night
/function outpost:targets/near
/function outpost:targets/far
/function outpost:targets/clear
```

机位命令只改变玩家位置与朝向，不会锁定相机。F1 隐藏界面。全景和远处双塔建议使用 16 区块渲染距离；近景录制可降低距离。

## 录制与恢复

原始 ZIP 是干净母版。每次大规模爆炸拍摄前，建议用它解压一个新的录制副本；模组弹药仍可能破坏地形和建筑。本地图没有后台反复重建场景的任务，也不会自动清理玩家摆放的载具。

建筑中使用可操作的高炉、烟熏炉、铁砧、锻造台、切石机、砂轮、木桶和感应铁门；外墙格栅、管线等部分功能方块则用于工业造型，并非整套自动生产设备。

## 实机核对

使用现有 Forge 1.20.1 + 卓越前线 + SBW Helldivers 环境打开并检查。验证了近/远距靶群按钮、重复生成、清除、固定日间、感应门、手册和控制台告示牌；预览图为实际 Minecraft 截图。交付母版不包含测试生成的靶怪、炮台、玩家 UUID 数据或测试专用模组代码。
