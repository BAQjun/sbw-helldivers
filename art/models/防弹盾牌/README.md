# 防弹盾牌

以标准防弹盾牌为基础制作，保留三段盾体、观察窗厚度、外缘折面、背面握把与固定带。观察窗为原有开孔。

- `防弹盾牌.bbmodel`：可直接在 Blockbench 打开的完整模型，贴图已内嵌。
- `backpack_shared.png`：复用现有背包共用色板，清除划痕、斑驳和不规则烘焙色块，重新整理黄色对位箭头。
- `预览/`：正面、背面、侧面及收拢状态预览。

保留 boss、shield_bot、shield_top 三个分组，以及 collapsed、extended、draw、holster 四段动作。伸缩位移来自标准原版骨骼动画。

优化方式为合并共面几何与规整材质分区，保持轮廓、结构厚度及握持部件。原始完整盾体为 4,517 三角形；当前模型包含重新制作的标记，共 4,262 三角形（2,960 个可编辑多边形）。未将四边面数量误作实际渲染三角形数量。
