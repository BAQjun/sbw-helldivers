# 其它炮台减面模型

本批包含机炮、火箭、火焰、特斯拉电塔及三种迫击炮。每个 `.bbmodel` 都包含贴图，可直接用 Blockbench 打开。

| 模型 | 枪体/塔体三角面：原版 → 本批 | 减少 | 整体三角面：原版 → 本批 |
| --- | ---: | ---: | ---: |
| 机炮炮台 | 3,876 → 3,276 | 15.5% | 13,616 → 13,016 |
| 毒气迫击炮哨戒炮 | 19,832 → 18,186 | 8.3% | 29,404 → 27,758 |
| 火焰炮台 | 21,912 → 20,312 | 7.3% | 31,652 → 30,052 |
| 火箭炮台 | 10,800 → 8,060 | 25.4% | 20,540 → 17,800 |
| 特斯拉电塔 | 29,588 → 27,046 | 8.6% | 29,588 → 27,046 |
| 电磁迫击炮哨戒炮 | 19,832 → 18,188 | 8.3% | 29,404 → 27,760 |
| 迫击炮哨戒炮 | 19,832 → 18,234 | 8.1% | 29,404 → 27,806 |

机炮与火箭将四个叠放方块组成的八角柱改成封闭连续网格，保留原来的外形。其余模型合并纯色平面的多余细分，并小幅减少曲面细分。标识、材质边界、开口边缘和明显棱线受到保护。

通用底座与侧板保持原样；骨架、动画和挂点保留。对照图位于 `../../预览/其它炮台减面/`，每张上、下两排展示两个相同角度，左侧为原模型，右侧为减面模型。

这是单独导出的模型候选，尚未替换正式版游戏资源；三角面减少比例不代表实际帧率提升。
