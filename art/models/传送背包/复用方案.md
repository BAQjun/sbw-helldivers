# 传送背包：解包与复用方案

已确认原资源为 displacement_backpack，独立于喷气背包与悬浮背包。原模型为 9,166 个三角面、10,056 个顶点、两套主体材质；骨骼层级共 27 个节点，包含辅助与 LOD 节点，不能当作 27 个活动关节。

## 可以复用

| 部分 | 可用来源 | 使用方式 |
|---|---|---|
| 肩带、腰带、扣具 | 当前喷气背包/悬浮背包的完整背部总成 | 复用已整理的网格与低噪点材质，整体调整尺寸和安装位置，保留完整背板、软垫与连接点 |
| 扣件 | 悬浮背包原参考 | 两个 68 面扣件通过边长组合比对一致；其余零件不能宣称原网格相同 |
| 黑灰壳体、黄色边条、金属件的配色 | 当前背包共用调色板 | 复用配色与材质设置；UV 随新结构重排 |
| 穿戴定位与后续递送流程 | 当前背包体系 | 后续接入时复用，当前阶段仅解包与结构分析 |

## 需调整后复用

背板与软垫的原版外形与旧背包相近，但不是完全相同的网格。复用整个已完成背部总成后，需按传送机体的背面安装轮廓调整，不能只保留背带再补一块简陋平板。两侧接点、肩带高度与腰带宽度需一起校准。

## 必须单独制作

- 上方传送圆环：外环、内侧分段条、左右绿色指示器与旋转部件。
- 中央 U 形机体、黄色边线、下部圆形组件与环座支撑。
- 两侧橙色散热鳍片和侧壳：保留大轮廓，密集细缝适合用简化贴图呈现。
- 本设备警示标识与绿色发光区域：使用简洁、清晰的低分辨率图形，不能照搬上一背包的标识。

## 动画与特效边界

骨骼包括 boss、shaker、halo、halo_left_indicator、halo_right_indicator、halo_fx、halo_spinner、left_thermal_vent 与 right_thermal_vent。圆环和散热组件应保留独立活动结构。

找到 charging、discharge、idle、idle_shakes、ready、shakes 六组动画。四组可解码的 JSON 动画为：charging、discharge、idle、ready；idle_shakes 与 shakes 的 JSON 导出遇到 NaN，已保留两份原始 animation 文件。GLB/Blender 中虽然有对应动作，不应直接视为两组问题动画已可靠还原。

原音效库 stratagems_displacement_pack.bnk 已保留，尚未核对每个事件。粒子原始数据已保留，当前预览为静态材质展示，未还原运行时传送特效。
