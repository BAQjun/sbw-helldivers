# Optional pod and laser sentry near-model experiment

Production runtime models remain unchanged. This pack is an alternative for the current full-detail models.

- Laser sentry including shared pod: 49,954 to 30,682 triangles (-38.6%).
- Shared pod: 18,430 to 15,336 triangles (-16.8%).
- Preserve primary silhouette, moving parts, rig, locators, heat indicators and atlas dimensions.
- Reduce curve tessellation and shallow engravings; replace overlapping nozzle boxes with continuous rings.
- Repair the shared cradle badge outer V with symmetric pixel geometry.

Zip the contents of `resourcepack/` (with `pack.mcmeta` at the zip root) and enable it in Minecraft's Resource Packs menu. Disable low-quality models and LOD when comparing. Removing the pack restores the default assets. Current supported mod version: 0.7.2, NeoForge 1.21.1 and Forge 1.20.1.

Editable sources are mirrored under `art/models/激光炮台减面测试/`.
This is an experiment, not a formal mod release or a replacement for the accepted full-detail model.
