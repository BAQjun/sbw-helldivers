# 反坦克支架 0.3.48

- 移除游戏中额外生成的重机枪弹链。原因是反坦克支架沿用了重机枪的父类，额外弹链绘制没有限定炮台种类；现在只为重机枪绘制。
- 射击后先放平炮管，之后完整运行 1 秒供弹动作，再恢复开火前的瞄准角度。放平和恢复所需时间另算，根据射击俯仰角与本炮台的最大转速计算。全部完成前不能再开火，重新上下炮台也不能跳过供弹。
- 人体工学仍为 32.5，转向响应及最大转速应用 0.65 倍速，均比上版降低 35%。当前最大转速约 160 度/秒。
- 放平和恢复使用平稳的加减速，实际最大速度不超过上述转速。以 30 度俯仰为例：放平 0.3 秒 + 供弹 1 秒 + 恢复 0.3 秒，总等待 1.6 秒。水平开火时无额外俯仰行程，仍为 1 秒。
- 瞄准视点后移 0.5 米，距炮台中心后方 1.85 米；保持中央视点与 4 倍瞄准。
- 展开改为平稳机械运动，炮管、座椅、踏板、瞄具等不再过冲或反向回摆。
- 保留炮台整体短促震动，炮管自身不伸缩。射击后震动独立触发，供弹待炮管放平后触发。

50 点血量、30 发备弹、直击 200、爆炸 20、内半径 3 米、外半径 7 米，以及弹尽踢下操作员并回收的设定保留。

BBMODEL/GLB 中的供弹片段是独立的 1 秒机构动作，放平和恢复由游戏根据当前角度与转向速度计算。预览视频是模型渲染，并非游戏实录。
