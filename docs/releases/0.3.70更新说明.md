# 0.3.70 目标标记

默认按 X 标记，控制设置可重新绑定。准星对准自己的标记时再次按 X 取消。每名玩家同时保留一个标记，同一维度的玩家共享显示。

- 生物显示菱形目标图标，敌对生物显示红色；只有地面/方块表面显示眼睛。炮台显示对应战备图标的纯白轮廓，保留原版图形，移除绿色卡片底色与边框。
- 图标、距离与底部箭头共用同一中轴，箭头尖端指向目标中心。菱形与刻线合为一张 19×19 像素图，眼睛同尺寸；两者逐像素检查水平/垂直对称，菱形另检查 90 度旋转对称。整数 GUI 像素显示，避免非整数缩放造成线条歪斜。
- 名称和 X 取消只在准星靠近标记时展开；移开仅显示图标与距离。方块标记名称为「特殊地点」。已建立的标记穿墙显示，生物标记随目标移动，死亡或失效后移除。
- 有效标记优先于炮台原有索敌目标；仍需符合炮台射程、友军保护及原有直射遮挡限制。迫击炮可以持续攻击标记的空地，取消或过期后停止后续发射，已经飞出的炮弹继续飞行。炮台标记仅提供信息，不会让炮台互相攻击。
- 成功标记敌人、普通目标、地点和取消时播放原版 ui_mission 对应事件的录音。无效选点和自然过期静音。

范围为 300 米，采用本地解包 SpottableComponentData 中普通敌人的 range.y；原版不同单位有不同范围，本版将普通 MC 目标统一为 300 米。持续时间目前为普通标记行为资料中的 8 秒；当前解包结构没有导出全局计时字段，不能把 8 秒称作直接解包值。详见「标记数据来源.json」。

图形依据本地图集的 A268 菱形、A213 R 通道眼睛、A125 R 通道角标及 hud_marker_generic 箭头，按统一像素网格规整绘制，并非逐字节复制原始抗锯齿图。

音效事件经原版 Wwise 名称哈希、事件动作和随机变体对应核实，使用原录音与事件增益；两层原引擎 Wwise 合成插件无法直接在 MC 执行，当前不包含这两层。详见「音效说明/目标标记原版音效证据.json」。

安装：以 sbw_helldiver-0.3.70-mc1.20.1.jar 替换旧附属模组，mods 中保留一份。Forge 1.20.1、卓越前线 0.8.9.1、Kotlin for Forge 环境保持一致；联机客户端与服务端均需本版，网络协议已更新。

验证：52 项服务端检查通过，包含标记射线、遮挡、跟随、过期、优先索敌、迫击炮空地射击和炮台排除。真实客户端验证 X 标记与取消、移动/穿墙、非敌对目标、地面与炮台图标、展开/简略 HUD，以及四类声音实际播放通道。测试场景在开始与结束均清理，保存后的实体区域另行核对。
