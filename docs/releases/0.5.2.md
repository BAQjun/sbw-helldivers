# 0.5.2

## 中文

- 下界禁用所有战备，包括呼叫超级驱逐舰与飞鹰重新武装；关闭冷却也无法绕过，战备列表显示不可用。
- 轨道精准打击开炮时，从超级驱逐舰方向播放原版舰炮闷响。

## English

- Disabled all stratagems in the Nether, including calling the Super Destroyer and Eagle Rearm. The HUD shows them as unavailable, even with cooldowns disabled.
- Orbital Precision Strike now plays the original cannon report from the Super Destroyer's bearing when it fires.
