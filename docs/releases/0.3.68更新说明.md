# 0.3.68 重机枪与榴弹墙开镜鼠标减速

重机枪支架、掷弹兵榴弹墙在右键 1.5 倍开镜时，鼠标转向速度降至正常的约 2/3。第一人称实际瞄具和第三人称放大均适用；松开右键、打开菜单或离开载具后恢复原速度，不修改玩家的全局鼠标设置。

沿用反坦克支架已有的处理方式，将其移至操控炮台的共享逻辑。反坦克支架 4 倍开镜仍为正常转向速度的 1/4，不会重复减速。

新版构建通过，最终游戏包的类变化仅限重机枪实体（含编译生成的 Companion）及反坦克实体。全部模型、贴图、动画、音效等 assets 资源与 0.3.67 逐项一致。本次未启动游戏客户端；此前镜位及部署方向修复保持不变。

用此 JAR 替换旧版 sbw_helldiver，mods 中只保留一份附属模组。
