# 0.3.67 榴弹墙镜位根因与垂直部署

已稳定复现 0.3.66 的首次开镜偏离。瞄具及枪口所在的转轴不在空投仓中心；旧镜位及枪口计算漏了这段转轴偏移随底座朝向的旋转。之前验收只使用 0 度部署朝向，因此掩盖了错误。换成 37 度时，实际模型与旧计算枪口相差约 7.4 厘米，镜窗离开中央。

修正瞄具镜位、枪口及瞄准解算共用的偏心转轴坐标；不再靠补偿屏幕偏移调整。第一人称初次右键开镜与第三人称瞄准后切回第一人称均使用同一实际镜位。保留第三人称抬高的视角与原生红点。

新空投的掷弹兵榴弹墙按战备球最初出手点到最终落点的水平连线部署，墙面与其垂直。记录出手点，支持球反弹及存档重载；玩家在投出后移动不会改变方向。单独同步并保存完整精度的底座角度，避免原版旋转包约 1.4 度量化造成显示偏斜。

32 项服务端检查通过，包括实际战备球落地、信标至空投仓的角度传递、原始出手点保存、共享墙体碰撞/血量及弹道。客户端在 37、-120、179、0 度部署朝向下，用真实右键事件验证首次开镜、连续转动、第三人称瞄准与切回第一人称，并检查镜位、枪口和完整精度角度。每次只生成一座测试炮台，前后清理，保存后零遗留炮台、墙片和榴弹。

模型、贴图、动画、音效及既有伤害和弹药设定不变。用本文件替换旧版 sbw_helldiver，mods 内只保留一份。Minecraft 1.20.1。已核对用户的卓越前线 0.8.9.2 与测试版 0.8.9.1 的关键相机及载具类字节相同；此次问题由附属模组的坐标计算造成。
