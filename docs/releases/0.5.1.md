# 0.5.1

## 中文

- 驱逐舰跃迁改为具有方位感的空间音效，并提升提示强度，方便辨认舰船所在方向。
- 轨道精准打击改为倒计时结束后开炮，默认准备 3 秒、炮弹飞行 1.5 秒，信标保留至命中。
- 补充原版轨道精准打击炮弹接近时的呼啸声，可分别配置开炮延迟与飞行时间。
- 模组音效传播距离统一不低于 64 格，保留原本更远的传播范围。

## English

- Super Destroyer jumps now use stronger spatial audio cues to indicate the ship's bearing.
- Orbital Precision Strike now fires after its countdown: 3 seconds of preparation followed by 1.5 seconds of shell flight by default. The beacon remains until impact.
- Added the original Helldivers 2 Orbital Precision Strike incoming shell whistle, with separate settings for firing delay and flight time.
- Raised mod sound propagation to a minimum of 64 blocks while preserving longer existing ranges.
