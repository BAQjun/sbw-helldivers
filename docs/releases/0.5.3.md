# 0.5.3

## 中文

- 超级驱逐舰跃迁改为沿舰艏方向在约 0.15 秒内高速飞入并骤停，撤离时在约 0.1 秒内加速飞离，并带有短促的方向拖光。
- 重新定位先离开原位置再进场，跃迁音效与运动起点同步。
- 跃迁动画按帧插值，保留三秒指令等待时间和固定支援位置。

## English

- Super Destroyers now warp in along their heading in about 0.15 seconds and stop sharply, then accelerate away in about 0.1 seconds, with a brief directional light trail.
- Relocation leaves the previous position before arriving at the new one, with warp audio synchronized to the start of motion.
- Warp movement interpolates between frames while preserving the three-second command delay and fixed support anchors.
