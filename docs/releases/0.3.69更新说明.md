# 0.3.69 防护罩生成器

已经接入空投与游戏，使用你修改后的纹理。护盾半径为最新指定的 15 米，增强了金色蜂窝纹路、球面边缘和命中波纹，仍可透视外部场景。

- 本体生命 100，沿用炮台的 50% 爆炸抗性。
- 护盾生命 640，每秒恢复 64，最多恢复到 640。
- 生命耗尽立即永久破盾，存档重载后也不会再生。本体被摧毁同样会停盾。
- 持续 40 秒，随后关闭护盾并收回发生器。
- 阻挡外部射入的弹射物；内部射击可穿出，生物可以进出。
- 高速子弹用运动路径检测，防止一帧跨过整个球面；吸收爆炸弹时不在护盾内部触发爆炸。
- 与空投平台同步升降，随后激活顶部组件；持续运行、停机、破盾、回收均有动画。绑定原版音库的展开、启动、维持、关闭与破盾录音事件。

安装：用 sbw_helldiver-0.3.69-mc1.20.1.jar 替换旧版附属模组，mods 中只保留一份。沿用现有 Minecraft Forge 1.20.1、卓越前线 0.8.9.1 与 Kotlin for Forge 环境。创造模式可取出防护罩生成器战备卡，也可用 `/give @s sbw_helldiver:shield_generator_stratagem`。

验证：42 项服务端检查通过；实际客户端完成两轮空投，确认 800 tick 寿命、22 次外部来弹、9 次内部弹射物穿出、破盾后不再恢复、原版声音取得实际播放通道，退出时循环音效为零。保存后的世界已检查，测试区域没有残留的附属模组实体，世界内没有残留的护盾生成器。

与 0.3.68 比较，原有模型、纹理、动画与录音均保持一致；五个共享资源文件只增加新条目。两张用户纹理与游戏图集中对应位置的像素完全一致。

音效说明：保留了原版事件中的录音层、原始增益与延迟。原引擎专用的 Wwise 合成插件层不能直接在 Minecraft 播放；完整来源记录见音效说明/防护罩生成器原版音效证据.json。
