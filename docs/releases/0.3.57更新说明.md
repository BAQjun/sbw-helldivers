# 0.3.57 更新说明

补上重机枪部署支架缺失的抛壳：每次左右枪管交替开火时，从对应枪体侧面的抛壳口生成一枚立体弹壳。抛壳位置依据已验收模型的左右 eject_cover 确定，随炮台水平转向和枪体俯仰变化；弹壳向对应外侧、略向上和向后飞出，之后独立旋转下落，碰到方块后停留约 5 秒。

沿用已有加特林尺寸的立体弹壳渲染，外形为带暗色开口的八边柱。没有额外修改模型、贴图、动画或音效。补发同步效果时按最新射击序号识别对应枪管，避免漏包后左右顺序错位。

保留 0.3.56 的打空后等待玩家自行下车、反坦克炮击屏幕震动与圆圈后坐曲线，以及之前的升降速度、名称和回收音效。安装时用本版 JAR 替换 mods 中的旧版模组。
