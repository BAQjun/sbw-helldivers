0.3.72 修正飞鹰战备图标与信标结束时机。

飞鹰空袭和飞鹰机枪扫射的物品、战备选择列表使用原图分离通道重新配色：飞机及边框为红橙色 RGB 220,100,85，弹药/效果符号为米白色 RGB 255,255,238，深色底为 RGB 25,3,1，与本次参考图取色一致。保留原始图形，R 通道用于飞机，G 通道用于弹药，分别合成。当前资源与游戏包已同步，后续飞鹰图标也沿用这套配色。

飞鹰信标分为倒计时和已抵达两个显示阶段：空袭在 4.1 秒、机枪扫射在 2.4 秒转为「已抵达」，光束和提示继续保留。每次调用跟踪它实际发射的炸弹/机炮弹，最后一发命中或结束后才移除信标。飞行中的弹药清单会保存，读档或暂未加载的弹药不会被直接当作已命中；旧版缺少清单的进行中调用采用兼容等待。异常中断的调用也有退出期限。

安装时以 sbw_helldiver-0.3.72-mc1.20.1.jar 替换旧附属模组，mods 中保留一份；联机客户端和服务端一并更新。飞鹰的完整接入说明仍见 0.3.71 更新说明。
