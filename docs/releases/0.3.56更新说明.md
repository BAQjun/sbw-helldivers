# 0.3.56 更新说明

重机枪部署支架打空弹药后保持玩家登乘状态和已展开状态。继续按住开火不会再发射，也不会启动回收。玩家自行下车后才开始回收，与反坦克炮台一致。

已对照用户提供的 QQ20261010-150041-HD.mp4，逐帧查看瞄准圆圈开火后的上冲与回落。反坦克单发后坐从普通逐 tick 衰减改为按发射时间计算的连续曲线：约 25 毫秒冲到峰值，短暂维持至约 65 毫秒，然后较快回落，约 0.5 秒完全复位。上跳峰值从 3° 提高到 4.5°，并加入小幅横向偏移。渲染帧按同一发射时间取样，避免峰值被 tick 插值抹平。

反坦克炮击的视角冲击加强，包含短促上抬和左右、上下的衰减震动，约 0.42 秒结束。效果不直接改写玩家鼠标视角值，结束后不留下永久偏移。空投仓内炮台主体的既有整体后坐动画继续播放。

圆圈依旧代表有效射击解算，投影、遮挡检测和弹道使用同一解算路径，保留此前确认的 5° 发射姿态限制。此轮参数是根据视频视觉节奏拟合，不宣称是原游戏的官方参数。

与 0.3.55 比较，全部资源文件相同；此前的加速升降、首次登乘放平、名称和回收音效均保留。安装时用本版 JAR 替换 mods 中旧版模组，保留现有依赖。
