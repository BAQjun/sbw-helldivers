## 中文

- 新增 Minecraft 1.21.1 / NeoForge 版本，适配卓越前线 0.8.9.2 与 Java 21。
- 迁移战备、信标球、冷却、配置界面、玩家空投及存档数据到新版接口。
- 适配新版模型与光影渲染，修复炮台支撑部件被错误裁剪、主体悬空，以及激光哨戒炮屏幕位置异常的问题。
- 保留精细与低质量模型切换，挖开地面后仍可看到空投仓。

需要 NeoForge 21.1.203+、卓越前线 0.8.9.2（NeoForge 1.21.1）和 Kotlin for Forge 5.10.0（NeoForge）。本文件为 NeoForge 1.21.1 专用构建；Forge 1.20.1 请继续使用对应的 Forge 文件。

## English

- Added a Minecraft 1.21.1 / NeoForge edition supporting Superb Warfare 0.8.9.2 and Java 21.
- Migrated stratagems, beacons, cooldowns, configuration screens, player hellpod drops, and saved data to the new APIs.
- Updated model and shader rendering. Fixed incorrectly culled sentry supports, floating turret bodies, and misplaced Laser Sentry displays.
- Retained detailed and low-quality model options, including visible buried hellpods when surrounding terrain is excavated.

Requires NeoForge 21.1.203+, Superb Warfare 0.8.9.2 for NeoForge 1.21.1, and Kotlin for Forge 5.10.0 for NeoForge. This is a NeoForge 1.21.1 build; use the corresponding Forge file for Minecraft 1.20.1.
