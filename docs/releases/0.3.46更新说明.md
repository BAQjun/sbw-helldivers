# 0.3.46 重机枪支架玩家伤害与下车修正

完整包：sbw_helldiver-0.3.46-mc1.20.1.jar，替换旧版插件 JAR。

重机枪支架不再套用原载具的上次驾驶者免伤规则。玩家可以攻击自己使用过的支架，正常扣血，血量耗尽后摧毁；保留现有伤害修正与爆炸抗性，并遵守显式无敌状态。

展开完成的固定支架现在正确标记为已落地、速度为零。原载具把未落地状态当作需要二次确认的离车操作；修正该状态后，一次 Alt 就使用原有正常下车流程。没有添加新的下车消息或改动其它载具规则。

0.3.45 的载具内战备球屏蔽、下车后松开 Alt 恢复战备功能继续保留。

构建和八项重机枪回归检查通过，其中新增了上次操作者伤害与摧毁检查，以及原下车处理使用的落地/静止判定检查。本次未启动图形游戏客户端。全部模型、贴图、动画、音效与 0.3.45 游戏包的 CRC 和大小一致。
