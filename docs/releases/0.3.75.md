# 0.3.75

- 新增仅通过管理员指令启动的玩家空投：`/helldivers drop <玩家> [<x> <y> <z>]`，支持玩家选择器和指定落点。
- 等待落点周围区块和地形就绪后再开始空投；多人落点在准备阶段预留，避免重叠。
- 玩家空投按参考视频调整制动高度与下降时序，并补齐乘员专属喷射启动声及子音轨延时。
- 玩家空投改用原版玩家入场声音；制动时衔接推进器点火与持续喷射，压低气流声并区分近远声层，落地时停止喷射声。
- 玩家乘空投仓从高空降落，下落时始终保持垂直俯视，可用 WASD 调整落点；站姿升起后先转为平视，再平滑推进至第一人称；出仓后恢复正常操作。
- 多名玩家同时空投时分开落点，避让已有空投仓；下落与出仓期间保护乘员，退出或移除仓体时安全释放。
- 新增 `/helldivers marking true|false` 控制标记功能，开关随世界保存并同步至玩家；关闭后清除现有标记及隐藏索敌指令。不带参数可查询状态。
- 空投仓运输期间暂停手持 TACZ 枪械的开火、瞄准和相机效果，避免干扰空投视角。
