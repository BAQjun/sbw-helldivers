# 0.3.66 榴弹墙镜位修正

第一人称右键开镜：最终相机位置直接固定在实际瞄具后，方向与发射器一致，不依赖卓越前线的开镜状态切换来决定镜位。转到炮架左右及俯仰极限后，继续拖动鼠标不会把视角移离瞄具。

第三人称镜位抬高，仍保持第三人称；右键只放大并显示瞄准圈，减少人物头部遮挡前方。

实际客户端重新验证持续转动鼠标至两侧及俯仰极限，并人为加入位置和角度偏移，检查最终相机仍固定在镜后。验证第三人称、原生红点、空弹留座和测试结束清理。此次不改变伤害、弹药、三个墙体碰撞区、已验收模型、贴图、动画或音效；沿用 0.3.65 的服务端检查基线。
