# 0.3.42 重机枪支架

完整游戏包：sbw_helldiver-0.3.42-mc1.20.1.jar。替换旧版插件 JAR，保留 Superb Warfare、Kotlin for Forge、GeckoLib 等原有依赖。

使用你最后修改的模型与原纹理。游戏版后踏板放平、抬高、向后延长并缩小间距；站位后移，视点比最初提高 0.35 格。连续弹链根据上下连接点变形，展开、回收、转动和俯仰时不会分成两段。

右键已展开的支架上机，左键射击，按住右键瞄准，左 Alt 脱离。300 发，600 RPM，每发 15 伤害；双管交替射击并伸缩。弹药耗尽后自动让操作员脱离并收回。Ergo 65 使用你指定的跟随公式和每秒 392.5 度上限。

未瞄准时显示左下角弹药，瞄准时使用 1.5 倍视野与固定中心点。圆圈用当前世界画面的投影矩阵显示枪口射线的首个接触点，两管取中线；快速转向会滞后，偏离过大时停在限定范围，横线随偏离展开。已经修复前后坐标误判导致圆圈始终停在边缘的问题。

模型审阅目录的「重机枪支架_连续弹链动画.glb」包含正确的蒙皮弹链，可查看空投、展开和回收。可编辑炮体在「模型/重机枪支架/重机枪支架_游戏适配版.bbmodel」。原用户修正版文件保留。

原版开火事件 2446321418（wep_heavy_machinegun）的可解码音频层按原增益与延迟混合，共 8 种变化。空投仓沿用已确认的仓体事件。独有抬枪事件尚未在当前解包音库中找到可确认素材，本版没有用其它炮台的抬枪声代替。

已通过 5 项服务器专项测试和隔离世界的真实客户端测试：展开、站立、第一人称瞄准、网络射击、转向跟随、圆圈投影、弹药耗尽脱离和收回。223 帧圆圈投影与独立相机方向校验一致；枪口与实际弹道起点最大误差低于 0.000001 格。用户纹理像素及原有 82 项炮台模型资源核对未变。
