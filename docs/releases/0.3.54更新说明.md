# 0.3.54 瞄准圆圈归中修正

针对圆圈接近中央准星后仍缓慢爬行的问题，保留大角度的原有追随响应，为最后一段追随加入最低收准速度。重机枪为 30°/秒，反坦克为约 21.2°/秒；每步最多移动剩余角差，不越过目标。此参数是模组手感调整，不是原游戏的官方换算公式。

固定炮台不再叠加持续的随机瞄准漂动。视角静止、后坐恢复后，有效瞄准稳定停在目标上。开火后坐仍保留，实际射击圆圈和射弹继续共用同一个有效瞄准解算，遵守枪口遮挡和 5° 修正限制。大幅甩动视角时，圆圈仍可能受到炮架机械追赶和 5° 限制的影响。

反坦克的人体工效保持 32.5，重机枪保持 65。机械转向速度、炮击声音、加速展开、供弹动画和弹尽后等待玩家自行下车再回收均保留。模型、贴图、动画、声音等全部 assets/data 资源与 0.3.53 逐字节相同。

构建成功，21 项实际服务端检查全部通过。新增检查让两种被玩家操作的炮台进行 5° 修正，确认 0.4 秒内完成有效瞄准追随，随后保持稳定，且无越过目标；同时检查跨越 ±180° 的追随方向和零时间步。既有真实炮弹 5° 限制、枪口遮挡、后坐恢复、镜头冲击、伤害、供弹及回收检查均通过。此次没有启动完整客户端，画面和实际操作手感尚未在客户端验证。

使用 sbw_helldiver-0.3.54-mc1.20.1.jar 替换旧版。联机客户端与服务端同步更新，网络协议仍为 5。
