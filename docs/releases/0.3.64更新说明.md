# 0.3.64 掷弹兵榴弹墙与武器瞄具

右键现在通过榴弹发射器上的实际瞄具观察，调用卓越前线原生红点渲染和载具镜位接口。1.5 倍放大，镜窗可透视，松开右键恢复原相机模式。镜位随发射器机械姿态变化。修正固定墙上的发射器转轴、镜位及枪口出生位置的对齐。

- 500 点血量、50% 爆炸抗性；展开宽墙阻挡生物及弹射物。
- 60 发，160 RPM；直击 5，爆炸 60，内半径 3.5 米、外半径 7.5 米。
- 正确白色砖墙图标，绿色地面与统一边框；战备输入：↓ → ↓ ← →。
- 原版展开与炮击音效、空投抬升与展开/供弹动画。
- 弹药耗尽不强制下车，玩家离开后也保留墙体。

29 项服务端检查通过。实际客户端验证原生瞄具、展开、射击与空弹留座；枪口测量最大误差约 0.0024 米。实景截图位于“预览/掷弹兵榴弹墙接入/实际游戏/瞄准.png”。

测试场景在运行前与结束时清理炮台、碰撞墙片及榴弹，并确认仅生成一座。保存后的存档检查为零遗留炮台、零碰撞墙片。

Minecraft 1.20.1 / Forge 47.2.0 / 卓越前线 0.8.9.1。替换旧附属模组，mods 内只保留一份 sbw_helldiver。沿用卓越前线自带的 GeckoLib，无需另装。
