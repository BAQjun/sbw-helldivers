# 0.3.40 启动崩溃修复

替换 0.3.39 附属模组 JAR，只保留新版本。

修复反坦克地雷空投组合动画中 loaded_mine_00 的零时刻缩放关键帧格式。原导出将 pre/post 放在通道根部，GeckoLib 将 pre 当成时间解析，启动时抛出 NumberFormatException。修复后以数字时间 0.0 包装原关键帧；保留原 pre/post 值。导出脚本同步修正，避免后续导出再次引入。

用用户日志中的 GeckoLib 4.4.6 解析器复现旧包崩溃，并检查最终 JAR 中全部 22 个动画文件、366 段动画，全部通过。构建通过。与 0.3.39 比较，游戏资源只修改这一动画文件，另更新版本元数据；模型、贴图、声音与地雷战斗逻辑一致。未追加完整客户端玩法测试，0.3.39 的玩法回归限制仍见其说明。
