## 中文

- 修复 NeoForge 1.21.1 中信标旁的战备信息、标记点等抬头显示缺失或位置异常的问题。
- 修复玩家操作型炮台的圆圈准星位置异常。
- 修复在模组列表中输入搜索文字导致游戏崩溃的问题，保留中文名称与 MODID 搜索支持。

- 修复自动哨戒炮传感器顶盖、瞄准盒和机匣盖板悬空的问题，同时修正盖板铰链与运动归属。
- 修正自动哨戒炮出仓音效延迟，精细与低质量模型同步更新。
- 自动哨戒炮修复同时适用于 Forge 1.20.1 与 NeoForge 1.21.1；抬头显示、准星与搜索修复针对 NeoForge 1.21.1。

## English

- Fixed missing or misplaced beacon information, target marks, and other world HUD elements on NeoForge 1.21.1.
- Fixed the position of the circular reticle on player-operated emplacements.
- Fixed a crash when searching the mod list, while retaining Chinese name and MODID search support.

- Fixed floating sensor caps, sight boxes, and receiver hatches on the Autocannon Sentry, including the hatch hinge and parent mechanism.
- Fixed delayed deployment audio for the Autocannon Sentry and updated both detailed and low-quality models.
- Autocannon fixes apply to both Forge 1.20.1 and NeoForge 1.21.1. HUD, reticle, and mod search fixes apply to NeoForge 1.21.1.
