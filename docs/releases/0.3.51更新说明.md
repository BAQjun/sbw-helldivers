# 0.3.51 操控炮台瞄准机制

重机枪支架和反坦克支架分离相机瞄准、武器有效瞄准与机械转向。中央准星仍固定，武器处理均采用人体工效 65、3.14/秒指数追随，并叠加少量连续平滑漂动。反坦克支架的机械转向仍沿用较慢的原配置，与武器处理速度分开。

按用户选择保留解包的 firenode_pose_limit = 5°。这个值约束有效射击方向与炮管方向之间的整体夹角，不能在横向与纵向分别超出 5°。因此武器内部处理方向可以更早追到玩家视线，但最终弹道与圆圈最多领先炮管 5°；不会出现炮管仍朝别处、圆圈却完全归中而射弹任意转向的情况。180° 是字段默认值，不是本地反坦克支架的实际值。重机枪相关解包武器条目也使用 5°。

圆圈投影的是约束之后的有效射击点。相机先选取世界空间目标，随后从实际枪口检查实体和方块遮挡，射弹使用同一解算方向；相机能看见目标、枪口被掩体挡住时，圆圈会落在掩体上。双管重机枪根据下一发所用枪口解算。保留原有细空心圆和屏幕边缘限制。

后坐力独立作用于武器瞄准处理：重机枪每发产生小幅上跳、连射叠加，停止射击后逐渐恢复；反坦克支架单发产生较大的上跳并恢复。机械炮架仍播放已有后坐动画，反坦克支架保持仓内炮台整体上扬，不增加炮管伸缩。

保留 0.3.50 的同步平台升降、升起后原声展开（1.572 秒）、不回正的 1 秒供弹、小型爆炸模板，以及两种支架的血量、弹药、伤害、放大倍率和弹尽回收。此次所有 assets/data 资源与 0.3.50 逐字节一致，未重绘图标或修改模型纹理。

构建成功，19 项实际服务端检查通过：6 项新增检查覆盖独立处理与机械转向、真实炮弹的 5° 限制、对角及反向瞄准边界、枪口遮挡、两种后坐力叠加与恢复、输入数据往返与无效目标；13 项原有检查继续通过。此次未运行完整游戏客户端，第三人称画面仍需在客户端观察。

替换旧模组为 sbw_helldiver-0.3.51-mc1.20.1.jar，勿同时安装多个版本。瞄准输入增加了世界空间目标数据，联机协议由 4 升至 5，客户端与服务端须同时更新到本版。

字段说明参考：[ProjectileWeaponComponent](https://github.com/shalzuth/HelldiversData/blob/master/data/components/ProjectileWeaponComponent.json)、[WeaponDataComponent](https://github.com/shalzuth/HelldiversData/blob/master/data/components/WeaponDataComponent.json)。实际 5° 值来自本地解包数据，而非上述字段默认值。射击冲量与漂动是本模组拟合参数，不声称是原游戏数值的直接单位换算。
