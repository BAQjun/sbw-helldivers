# 0.3.53 反坦克支架手感调整

观察用户提供的 QQ20261010-150041-HD.mp4 后，按开炮瞬间短促冲击、随后落稳的方向调整反馈。此次是对观感的拟合，不声称精确复现参考视频的原游戏参数。

反坦克支架的有效瞄准人体工效从 65 恢复为 32.5，即重机枪支架 65 的一半。机械转向人体工效仍为 32.5，并保留已有较慢转向配置。有效瞄准的基础指数响应从 3.14/秒变为 1.57/秒；20 TPS 下每 tick 消除约 7.55% 剩余误差，重机枪仍约 14.5%。有效瞄准与机械姿态继续独立，最终射击方向仍遵守 5° 修正限制。

反坦克支架开炮时增加短促镜头上冲和少量震动，约 0.035 秒达到峰值，0.32 秒落稳，不修改玩家鼠标输入角度。炮台主体保留既有整体上扬，炮管不单独伸缩。圆圈保留上一版 3° 单发上跳。中央瞄准射线使用实际载具相机方向，避免镜头震动时准星指向与送往服务端的目标脱节。镜头冲击与瞄准后坐、模型后坐分别处理。

保留 0.3.52 的炮击录音 +6 dB、1.6 倍展开速度与同步声音、弹尽后等待玩家自行下车再回收。备弹 30、血量 50、1 秒供弹、直击 200、爆炸 20、内半径 3 米、外半径 7 米、4 倍瞄准均不变。全部 assets/data 资源与 0.3.52 逐字节相同。

替换旧模组为 sbw_helldiver-0.3.53-mc1.20.1.jar。联机客户端与服务端一起更新，网络协议仍为 5。
