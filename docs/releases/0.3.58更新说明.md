# 0.3.58 更新说明

重机枪部署支架两侧的抛壳口盖板及弹链出口盖板改为向外翻开，左右镜像、角度一致。抬升最后一段翻开，抬升后的仰起待机、首次登乘放平以及正常操作状态均保持打开；回收起始阶段合上。

抛壳继续从大盖板下方的出口向外抛出。保留上一版左右交替的立体弹壳、旋转下落与落地停留。

完整空投组合与独立游戏适配模型均已更新，GLB 和左右近景重新生成。近景在“预览/0.3.58重机枪抛壳口”。独立模型的默认姿态为盖板打开；组合模型请播放已部署或待机动画查看。几何、贴图、音效、供弹及射击参数未改。

构建成功，25 项服务端检查通过；最终 JAR 核对确认只修改重机枪动画资源，并检查部署、待机、首次登乘、损坏及回收各阶段的盖板姿态。本轮未启动完整游戏客户端，近景为最终模型的预览。

安装时用本版 JAR 替换 mods 中旧版本模组，保留现有依赖。
