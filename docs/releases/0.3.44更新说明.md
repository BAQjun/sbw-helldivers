# 0.3.44 重机枪支架瞄准与后坐修正

完整包：sbw_helldiver-0.3.44-mc1.20.1.jar。替换旧版插件 JAR，保留现有依赖。

第三人称镜头继续保持头部后上方、左右居中。镜头与玩家视角使用同一朝向；枪管追随画面中心的实际瞄准点，并补偿镜头与枪口高度、旋转中心及枪管轴线偏置。第一人称也使用相同的实际瞄准点。枪口圆圈继续显示实际枪口方向，保留 Ergo 转向滞后及偏移限制。

双管后坐最大行程从 0.65 增至 2.2 模型单位（约 4.1 厘米 → 13.75 厘米），动作时长从 0.10 秒缩短为 0.065 秒。快速后缩后立即复位，600 RPM、左右交替、300 发弹药与 15 点伤害维持现有设定。

隔离实际游戏检查通过：第三人称 8 米、30 米目标瞄准回中，快速转向仍有实际枪口滞后；两根枪管实测后坐峰值约 13.5 厘米。网络开火、弹药耗尽与回收均验证。六项服务器回归检查通过。最新实机截图在「预览/重机枪支架实装」。

与 0.3.43 比较，游戏资产仅修改重机枪后坐动画；用户绘制的贴图、图标、模型几何、连续弹链、音效和其它炮台资源经逐文件核对保持一致。模型目录的游戏适配 BBMODEL 与审阅 GLB 已同步后坐动画。
